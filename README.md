独立部署的趣C刷题系统（与课导培训刷题中心分开维护）。

## 在线访问

GitHub Pages 开启后：`https://zhuqiannan101.github.io/qiannan-quc/`

## 内容

- `index.html` —— 趣C刷题首页
- `quiz.html` / `quiz_light.html` —— 刷题页面
- `tongshi.html` / `canyu.html` —— 通识与参与页
- `exam-*.html` —— 考试页面
- `quiz_data.json` / `quiz_day*.json` —— 题库数据
- `img_online/` —— 题目图片库（174 张）
- `kaitxue/` / `results/` —— 附属页面与结果数据
- QC课导刷题库 md 文档
